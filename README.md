# 刘万锁个人主页

双击 `index.html` 即可离线预览。上传本目录全部文件到静态网站根目录即可，无须安装依赖、构建或联网加载字体。

- `index.html`：主页文字、导航、三栏内容。
- `styles.css`：桌面、笔记本和手机布局。
- `tools.html`：工具与资源入口页。
- `script.js`：联系邮箱弹窗与复制功能。邮箱在 `index.html` 的 `contact-email` 和 `mailto:` 链接中配置，当前为 `loerwalson@sina.com`。点击复制后显示成功提示；如果浏览器拒绝自动复制，会选中邮箱并提示手动复制。
- `assets/lwsimulation-logo.png`：用户提供的 lwSimulation 原始标志，导航栏通过 CSS 隐藏原图外围留白，图像文件不做重绘或修改。
- `brand.css`：共用标志的显示区域，以及主页 Juno 入口样式。
- `juno.html`、`juno.css`、`juno.js`：杭州 Juno 超算中心独立介绍页，7 个逐屏章节，支持原生滚动、章节导航、上一屏/下一屏与 PageUp/PageDown/Home/End；手机使用自然滚动，尊重系统减少动态效果设置。
- Juno 内容参考用户上传的《Juno_页面骨架_六种设计方案.pdf》。多物理场关系、管路进气和微通道出口均为可交互概念示意，并非仿真计算结果。AI 辅助优化按原资料标为拟建服务。
- `assets/hero.png`：基于用户最新原始照片及最终设计图，用内置图像工具生成的人像与水坝合成资源。并非原照的无损抠图，人物和背景可有生成差异。
- `assets/favicon.svg`：网站图标。水坝为实际 PNG 位图，不是 SVG 占位图。

首页使用宽度驱动的响应式布局，不使用 `max-height` 或 `vh` 来压缩桌面 Hero。导航保留现有实际可用的页面与栏目，窄屏可换行，页面内容允许自然纵向滚动。

### 首页布局与图片接口

- 桌面页框最大宽度为 1600px，超宽屏居中。Hero 使用 43% / 57% 两列，正文参与正常布局，容器可随文字内容增高。
- 合成图按容器宽度缩放，底部、右侧对齐，不按屏幕高度放大人物。文字侧渐变层改善可读性。
- 1000px 及以下改为上下布局；600px 及以下信息区改为单列。导航和操作按钮允许换行。
- 后续拆分图片：给 Hero 的 section 添加 `hero--layered` 类，将 `img.hero-art` 的图片替换为纯背景图，在 `.hero-visual` 内追加透明人像 `<img class="hero-portrait" src="assets/portrait.png" alt="刘万锁">`。纯装饰背景应使用空 `alt`，并同步更新图片尺寸属性。
- 透明人像位置通过 `--portrait-width`、`--portrait-right` 调整，移动端使用 `--portrait-width-mobile`、`--portrait-right-mobile`；无需修改正文布局。当前尚未提供独立透明人像，继续使用原合成图。

验证（2026-09-24）：Chromium 实际渲染检查覆盖 1366×768、1366×1080、1920×1080、2560×1440、3840×2160、1024×768、1000×800、768×1024、390×844、320×568；均无页面横向溢出，图片加载和导航显示正常，联系弹窗可打开并通过 Escape 关闭。相同 1366px 宽度、不同高度的 Hero 与图片尺寸完全一致。工具页另检查 320、768、1366px 宽度。

GitHub Pages 使用相对资源地址。样式与脚本的引用包含版本参数，更新这些资源时同步修改两个 HTML 文件的版本参数，避免浏览器混用旧缓存。已在线核对服务器样式与本地文件一致。

正式主页：https://lwsimulation.github.io/ 。Juno 页面：https://lwsimulation.github.io/juno.html 。离线时直接打开 `juno.html`；不需要构建工具或服务端。

图片生成提示词摘要：以最终设计稿限定 2.37:1 构图，以最新原始白衣照片限定人物身份，保持面部比例和自然纹理；左侧约43%浅白留空，右侧大半身人物；浅蓝灰低对比水库、群山与水坝；不生成文字、按钮或界面。使用内置 imagegen，原始生成资产保存为 assets/hero.png。

### 沉积腔室交互研究页

主页“查看我的研究”连接到 `research.html`。页面由 `research.css`、`research.js` 和本地 `assets/vendor/` 三维依赖组成，不请求外部 CDN。通过 GitHub Pages 或本地 HTTP 服务浏览；ES 模块不支持直接双击 HTML 的 file 协议预览。

- 透明圆柱腔室、顶部入口、带 42 个真实孔洞的喷淋板、基片、底部收集锥与排气口。
- 彩色流线贯穿入口、上腔分流、喷淋孔、射流区、基片外围和底部排气口。粒子沿路径按局部模型速度运动，颜色使用固定相对速度色标，不代表 m/s。
- 温度场、基片旋转、等离子体电场可以独立切换或叠加，分别改变射流展宽、切向旋转和定向加速；入口流量可调。此模型为有边界约束的参数化概念示意，不是 Navier–Stokes、能量或等离子体方程的数值求解，也不预测具体设备性能。
- 拖拽旋转、滚轮或双指缩放；聚焦三维视图后也可用方向键旋转、加减键缩放。支持暂停与重置视角；系统选择减少动态效果时默认暂停。WebGL 不可用时显示重试说明。
- `research.js` 的 `sample()` 定义流路和各物理场影响。喷淋板区保持孔位对齐，经过基片上方时先向外偏转再向下流动。后续可替换为真实 CFD 采样结果，并同步更换色标与说明。
- Three.js 固定为 0.160.1，保留 MIT 许可证于 `assets/vendor/THREE-LICENSE.txt`；`OrbitControls.js` 为同版本官方控制器。文档：[Three.js](https://threejs.org/docs/)。

验证（2026-09-24）：Chromium 渲染与交互检查覆盖 1366×768、1920×1080、2560×1440、3840×2160、768×1024、390×844、320×568；检查物理场叠加与移除、流量调节、鼠标拖拽、键盘旋转缩放、手机触控、暂停/视角重置、主页入口、减少动态效果设置及 WebGL 不可用提示。全部 8 种物理场组合与 3 档流量共 1,009,008 个流路采样点通过喷淋孔、腔壁及基片几何约束检查。
