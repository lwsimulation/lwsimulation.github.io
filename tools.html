Knudsen 数计算器

Kn = λ / L，用于衡量气体稀薄程度以及连续介质假设是否仍然适用。

Kn = λ / L
直接由平均自由程与特征长度计算。
Kn：Knudsen 数，无量纲。
λ：分子平均自由程，长度单位可选 m、mm、μm、nm。
L：特征长度，例如微通道直径、孔径或局部几何尺度，长度单位可选 m、mm、μm、nm。
λ = kBT / (√2 π d2 p),   Kn = λ / L
基于理想气体硬球模型先估算平均自由程，再计算 Kn。
kB：Boltzmann 常数，1.380649 × 10−23 J/K。
T：气体绝对温度，单位 K。
p：气体绝对压力，可输入 Pa、kPa、mbar 或 Torr。
d：分子有效碰撞直径，可输入 nm 或 Å；它是模型参数，不同资料可能略有差异。
λ：计算得到的分子平均自由程，单位 m。
L：特征长度，例如通道高度、孔径或局部尺度，单位可选 m、mm、μm、nm。

预设值仅用于快速估算；严谨计算应采用与你所用碰撞模型一致的有效分子直径。

可能适用的计算方法

常用流态划分

连续流Kn < 0.01 · NS / 常规 CFD
滑移流0.01 ≤ Kn < 0.1 · 滑移边界 NS
过渡流0.1 ≤ Kn < 10 · DSMC 或 NS–DSMC 混合
自由分子流Kn ≥ 10 · DSMC / TPMC / 自由分子模型

这里采用的是常见工程划分。对微通道、喷口、强梯度流动或跨流态系统，单个全局 Kn 只能作为初步判断；实际建模还应关注局部 Kn、壁面条件、压力梯度以及非平衡效应。
